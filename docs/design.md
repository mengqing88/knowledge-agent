# 工作台设计提案

用途：研究者在电脑上阅读论文、提问与逐项检查证据；静态长文为主体，操作状态为辅助。三栏在宽屏同时容纳材料、答案和证据；窄屏按顺序折叠。

Design Read：greenfield / 克制的学术阅读工具；视觉变化 3、动效 2、信息密度 7、图像依赖 1、品牌约束 2。以稳定栅格、可读正文、真实版本信息承载内容。

设计系统：暖白 #f7f7f2，纸白 #ffffff，墨色 #202d2a，青绿 #216c59，次级灰 #75817a，边框 #e2e6df。正文系统中文无衬线、标题可用系统宋体；技术编号使用等宽。8px 基础间距，8px 卡片圆角，弹层轻阴影，160ms 状态过渡并尊重 reduced-motion。焦点与错误状态明确可见。

先展示 v0 布局，用户确认后完成工作台交互。
