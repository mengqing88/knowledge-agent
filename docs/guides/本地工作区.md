# 本地工作区

代码和文档按同一结构在本地与 GitHub 同步。下列本机内容保留在原路径，由 `.gitignore` 排除，不为整理而移动运行数据或清空环境。

| 路径 | 内容 |
| --- | --- |
| `.env` | 本机服务与模型配置 |
| `.venv/`、`frontend/node_modules/` | 已安装依赖 |
| `frontend/dist/` | 可由后端提供的前端构建产物 |
| `data/` | 本机上传资料、数据库/演示状态、进程记录、日志和初始化账号文件 |
| `tmp/independent-review-20261115/` | 12 题匿名人工试评材料；`reviewer.zip` 可交给评审者，`operator-key.json` 仅操作者保管 |
| `tmp/rag-models/`、`tmp/rag-reranker-env/` | 本地重排模型权重及实验推理环境 |
| `tmp/closure-3yuan/` | 3 元收尾时的工程日志与浏览器证据 |
| `tmp/isolated-acceptance-20261114*/` | 隔离存储/队列联调证据 |
| `tmp/reports/` | 整理后常规检查与实验的新报告 |
| `tmp/project-organization-20261115/` | 本次整理的搬移清单、原文件哈希与验证记录 |
| `evaluation/results/public-3yuan-v1-bge-offline-v1/` | 中断的本地尝试，保留但不提交；已保存的离线对照是同层 v2 |

更早的 `tmp/*-validation`、`tmp/*-before*` 目录属于历史测试证据，不是日常启动入口。没有在本轮删除、移动或打包这些数据，避免破坏已记录的路径或本地环境。

日常只需看根目录 README、`backend/`、`frontend/` 和 `docs/README.md`。评审包原路径保持不变：
