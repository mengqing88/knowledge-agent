Mode: Extension. Audience: team members querying internal documents on laptops. Narrative role: working tool; quiet and approachable. Keep library / question / evidence. Add login, document management and members as compact forms and dialogs.

Design Read: workbench; editorial utility; extension. Visual variance 2/10, motion 1/10, density 6/10, asset dependence 1/10, fidelity 10/10. Existing tokens and type remain; filters, history and expandable trace handle density.

Retained tokens: background #f7f7f2; ink #202d2a; teal #216c59 and #164d41; mint #e5efe8; border #e2e6df. Serif headings and existing Chinese UI fonts. Spacing in 4/8 px steps; 6–12 px radii; restrained modal elevation. Brief hover/focus transitions, respecting reduced motion.

Protected contracts: API route names and citation links; immutable snapshots; file hashes and raw offsets; keyboard form submission; prior teaching documents. Product copy changes from papers to team documents follow the confirmed scope replacement. Demo mode stays explicit and scores stay empty until measured.
